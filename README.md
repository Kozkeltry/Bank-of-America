# Bank-of-America

Простое консольное приложение «Банковская система», разработанное на C++ для практики ключевых концепций объектно-ориентированного программирования (ООП).

This is a simple console-based banking application written in C++ to demonstrate and practice core Object-Oriented Programming (OOP) concepts.

## 🚀 Ключевые особенности / Features

* **Инкапсуляция (Encapsulation):** Все важные данные аккаунта (баланс, пароль) скрыты в `private` секции класса и защищены от прямого изменения извне.
* **Авторизация (Authentication):** Реализована система входа по номеру счета и текстовому паролю.
* **Указатели (Pointers):** Программа использует указатели (`BankAccount*`) для динамического выбора и переключения между аккаунтами пользователей в `main()`.
* **Безопасность транзакций (Validation):** Внедрена проверка баланса при снятии средств, которая не позволяет балансу уйти в минус.
* **Интерактивное меню (Interactive UI):** Меню работает в бесконечном цикле `while`, позволяя совершать несколько операций подряд без перезапуска программы.

## 🛠️ Функционал / Functionality

После успешного входа пользователь может:
1. Проверить текущий баланс.
2. Пополнить счет на любую сумму.
3. Снять наличные (с проверкой на доступность средств).
4. Посмотреть номер своего счета.
5. Безопасно выйти из аккаунта обратно в систему.

## 💻 Стек технологий / Tech Stack

* **Language:** C++11 (или новее)
* **Standard Libraries Used:** `<iostream>`, `<string>`

## 📖 Как запустить / How to Run

1. Скомпилируйте файл `main.cpp` с помощью любого компилятора C++ (например, GCC):
   ```bash
   g++ main.cpp -o bank_system
   ```
2. Запустите собранный файл:
   ```bash
   ./bank_system
   ```
3. Для тестирования в программе уже созданы два тестовых аккаунта:
   * **Алексей Морозов:** Номер счета `298167234`, Пароль `Alexei1234`
   * **Иван Петрович:** Номер счета `556141860`, Пароль `IvanPetrovich4321`
